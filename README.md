# Kajeeth Kumar — Research Portfolio

A responsive, static personal research portfolio built with HTML, CSS and vanilla JavaScript. It is ready for GitHub Pages.

## Publish with GitHub Pages

1. Sign in to GitHub as **kajeethkumar**.
2. Create a new **public** repository named exactly `kajeethkumar.github.io`.
3. Upload the contents of this folder (not the enclosing folder) to the repository root:
   - `index.html`
   - `assets/style.css`
   - `assets/main.js`
   - `README.md`
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for the deployment to finish. Your website will be available at:

   https://kajeethkumar.github.io/

## Customize before publishing

Search `index.html` and replace the placeholders:
- Add your verified institutional affiliation, current role and short biography.
- Add real publication titles, author lists, venue, year, DOI and paper links.
- Replace the Google Scholar and LinkedIn links with your actual profile URLs.
- Add repository links to projects only when those repositories are public.
- Add a professional email address if you want it displayed.

The current page deliberately describes research directions rather than claiming unverified publications, positions, awards or affiliations.

## Local preview

Open `index.html` in a browser. The Google Fonts import requires an internet connection; the page otherwise works as a static site.

## Updating the site

Edit the files locally or directly in GitHub. Commit changes to `main`; GitHub Pages will automatically rebuild the site.
